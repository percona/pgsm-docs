# Version 2.4.1 ({{date.2_4_1}})

 [Install `pg_stat_monitor`](../install.md){.md-button}

## Release highlights

This release adds PostgreSQL 19 general availability support.

## Improvements

### PostgreSQL 19 support

[PG-2424](https://perconadev.atlassian.net/browse/PG-2424) - `pg_stat_monitor` now supports PostgreSQL 19. On PostgreSQL 19, the `pg_stat_monitor` view includes the **generic_plan_calls** and **custom_plan_calls** counters, which track how many times a prepared statement was executed with a generic or a custom plan. See the [`pg_stat_monitor` view reference](../reference.md#postgresql-19) for the full list of columns.

Support for property graphs, which was added in version 2.4.0 for PostgreSQL 19 beta 3, is removed because the feature was reverted from PostgreSQL 19. Property graphs are therefore no longer listed in the `relations` column.

### Other improvements

* The query plan text is now built only when it is going to be stored, which reduces overhead when [`pg_stat_monitor.pgsm_enable_query_plan`](../configuration.md#pg_stat_monitorpgsm_enable_query_plan) is enabled, especially for nested statements when only top-level statements are tracked

## Bug fixes

* Statements that have no query ID are now ignored, matching the behavior of `pg_stat_statements`
* [PG-2857](https://perconadev.atlassian.net/browse/PG-2857) - Improved the stability of the regression tests
